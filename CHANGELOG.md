# Changelog

## Unreleased — experimental V1 preparation

### Public baseline demonstration

- Migrated answer, adapter and retrieval self-tests to a separate fictional
  regression profile; runtime profile and answer algorithms are unchanged.
- Added an automated guard against private-profile/network/model access in those tests.

- Added explicit `--public-demo` mode to the existing pipeline, with nine fictional
  regression cases and no API, model load or private-profile access.
- Added four standard-library tests and Windows/Linux GitHub Actions workflow.
- Verified the public path in a new dependency-free Windows environment.
- Kept runtime integration defaults unchanged; full ML/RAG artifact portability
  remains a separate milestone. Hosted CI has not yet run.

### Documentation

- Prepared the first independent public source repository under MIT, with an
  authentic reviewed training still and source-hashed metrics extract.
- Moved local catalog and integration paths into ignored compatibility settings;
  preserved the private runtime configuration and historical source-map backup.

- Added public English project narrative and Portuguese digest.
- Added architecture, RAG, training, reproduction and engineering-history guides.
- Added editable vector visuals and Mermaid architecture/mind maps.
- Recorded publication blockers and video review plan.
- Added a source-hashed, path-free extract of the selected training metrics.
- Matched sampled video frames to earlier training runs and added one reviewed
  authentic still, explicitly separate from the selected checkpoint's results.
- Recorded source-level privacy findings in legacy profile-based self-tests.
- Excluded original recordings and private historical journal from public Git.

### Existing local implementation, documented retrospectively

- CPU full-parameter fine-tuning and saved-checkpoint diagnostics.
- Real-question preparation, annotation review and context experiments.
- Qdrant/FTS5 hybrid retrieval with OpenRouter embeddings and cache.
- Grounded answer generation, shared budgets and isolated worker integration.

No release tag or public deployment is implied. No training, API use or browser
submission was performed. The answer algorithm and integration defaults are
unchanged; the public demonstration adds a new explicit invocation mode.
